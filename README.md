## Многофункциональный таймер 

# Здесь разрабатываем многофункциональный таймер. 

Концепции:
1. Таймер предназначен для формирования сигналов в заданное время.
2. Могут существовать два различных сигнала. Например:
	- начало временного интервала (условно, включение);
	- конец временного интервала (условно, выключение)
3. Задание интервалов должно быть возможно с помощью некоторых 
элементов управления. Возмножно, кнопка и энкодер.
4. Задание интервало возможно с помощью компьютерной программы 
с последующей записью результатов в ПЗУ устройства.
5. Отображение программы функционирования осуществляется с
помощью индикатора. Предположительно, 16х2 или 20х4.
6. Должно быть несколько записанных программ, а нужная выбирается
с помощью элементов управления. 

# Порядок работы устройства.

1. При включении происходит чтение из ПЗУ установленных программ
и вывод их на индикатор.
2. Курсор устанавливается на первую программу.
3. Курсор двигается по программам однократным нажатием на кнопку. 
Движение осуществляется циклически. 
4. Двойным нажатием запускается программа.
5. После окончания выполнения программы, курсор остается на только что 
выполненной программе. 
6. Режим программирования включается длинным нажатием. Редактируется
программа на которую указывает курсор. 
7. Для ввода новой программы всегда существует пустая строка, на 
которую можно попасть при циклическом обходе программ.
8. Пока не придумал, как сделать удаление программы.

# Формат отображение программы таймера.

Программа отображается в виде строки, состоящей из последовательности
следующих символов:

- цифра (0-9) используется для указания времени задержки, может
быть последовательностью;
- символ '+' - обозначает включение (с соответсвующим звуковым сигналом);
- символ '-' - обозначает выключение(с соответсвующим звуковым сигналом);
- символ 'x' - обозначает, что предыдущую последовательность
событий выполнить, такое количество раз, какое обозначено числом, 
следующим за знаком. 
- символ '.' - обозначает конец программы

Пример:
+25-10х5.
означает, включить, подождать 25 секунд, выключить, подождать 10 секунд,
и повторить все это 5 раз.
10+50-10+30-.
означает через десять секунд после включения прибора включить нагрузку,
подождать 50 секунд и выключить, подождать 10 секунд и опять включить, 
подождать 30 секунд и выключить.
